## Task 13: What are Generics? Benefits of Generics. Can you explain with code?

### Explanation

Generics allow us to write reusable code that can work with different
data types while maintaining type safety.

Generics were introduced in Java 5.

Think of Generics as a template where the actual data type is specified
when the class, interface, or method is used.

### Why Were Generics Introduced?

Before Generics:

- No Type Safety
- Explicit Casting Required
- Runtime Errors Possible

Generics solved these problems by introducing:

- Compile-Time Type Checking
- Type Safety
- Reusability

### Without Generics

```java
import java.util.*;

public class Demo {

    public static void main(String[] args) {

        List list = new ArrayList();

        list.add("Java");

        list.add(100);

        String value =
            (String) list.get(0);

    }

}
```

### Problem

The compiler allows:

```text
"Java"

100
```

Wrong casting causes runtime errors.

```java
String value =
    (String) list.get(1);
```

Runtime Error:

```text
Integer cannot be cast to String
```

### With Generics

```java
import java.util.*;

public class Demo {

    public static void main(String[] args) {

        List<String> list =
            new ArrayList<>();

        list.add("Java");

        list.add("Spring");

        String value =
            list.get(0);

        System.out.println(value);

    }
}
```

### Output

```text
Java
```

### Benefits Of Generics

1. Type Safety

2. Compile-Time Error Checking

3. Reusable Code

4. No Explicit Casting

5. Better Readability

6. Fewer Runtime Errors

### Generic Class

```java
class Box<T> {

        this.value = value;
```

### Using Generic Class

### 1. Explain why Lambda Expressions were introduced in Java 8

### Explanation

Before Java 8, if developers wanted to pass some behavior or logic to a
method, they usually had to create:

- Separate Classes
- Anonymous Classes

This resulted in a lot of unnecessary code.

Java developers wanted a simpler way to represent small pieces of logic.

Lambda Expressions were introduced to make code:

- Smaller
- Cleaner
- More Readable
- Easier To Maintain

A Lambda Expression is an anonymous function.

It allows us to treat behavior as data and pass it directly to methods.

---

### Before Java 8

#### Code

```java
Runnable task = new Runnable() {

    @Override
    public void run() {

        System.out.println("Task Running");

    }
};

task.run();
```

#### Output

```text
Task Running
```

#### Output Explanation

A Runnable object is created using an anonymous class and then executed.

Although the logic contains only one statement, we still write multiple
lines of code.

---

### Using Lambda Expression

#### Code

```java
Runnable task = () -> {

    System.out.println("Task Running");

};

task.run();
```

#### Output

```text
Task Running
```

#### Output Explanation

The Lambda directly provides the implementation of the run() method.

No anonymous class is required.

---

### Benefits

```text
✓ Less Boilerplate Code

✓ Easier Maintenance

✓ Works Seamlessly With Streams
```

### 5. Why were Default Methods added to Interfaces in Java 8?

### The Problem

Suppose an interface is implemented by thousands of classes.

#### Existing Interface

```java
interface Vehicle {

    void start();

}
```

Now assume Java wants to add:

```java
void stop();
```

Every existing implementation breaks.

Compilation fails.

---

### Java 8 Solution

Default Methods allow interfaces to provide method implementations.

#### Code

```java
interface Vehicle {

    void start();

    default void stop() {

        System.out.println(
            "Vehicle Stopped"
        );

    }

}
```

#### Implementation

```java
class Car implements Vehicle {

    public void start() {

        System.out.println(
            "Car Started"
        );

    }

}
```

#### Usage

```java
Car car = new Car();

car.start();

car.stop();
```

#### Output

```text
Car Started

Vehicle Stopped
```

#### Output Explanation

The class implements only start().

The stop() implementation is inherited from the interface.

---

### Benefits

```text
✓ Backward Compatibility

✓ Interface Evolution

✓ Framework Upgrades

✓ No Breaking Changes
```
