    Node root = new Node(10);

    root.left = new Node(5);
    root.right = new Node(20);

    root.left.left = new Node(3);
    root.left.right = new Node(7);

    root.right.left = new Node(15);
    root.right.right = new Node(25);

    int searchValue = 15;

    if(search(root, searchValue)) {
        System.out.println(searchValue + " Found");
    } else {
        System.out.println(searchValue + " Not Found");
    }
}

public static boolean search(Node root, int target) {

    if(root == null) {
        return false;
    }

    if(root.val == target) {
        return true;
    }

    if(target < root.val) {
        return search(root.left, target);
    }

    return search(root.right, target);

}

}

# EXPLANATION:

Both BFS and DFS are tree/graph traversal algorithms.

The main difference is the order in which nodes are visited.

public static void bfs(
    Map<Integer, List<Integer>> graph,
    int start
) {

    Queue<Integer> queue =
        new LinkedList<>();

    Set<Integer> visited =
        new HashSet<>();

    queue.offer(start);
    visited.add(start);

    while(!queue.isEmpty()) {

        int node = queue.poll();

        System.out.print(node + " ");

        for(int neighbor : graph.get(node)) {

            if(!visited.contains(neighbor)) {

                visited.add(neighbor);

                queue.offer(neighbor);

            }

        }

    }

}

# EXPLANATION:

A Cycle exists when we can return to a previously visited node through
a different path.

Example:

A -> B -> C -> A

This forms a cycle.

```text
    1
   / \
  2   3
   \ /
    4
```

Cycle Exists:

1 -> 2 -> 4 -> 3 -> 1

For Undirected Graphs:

Use DFS and track:

1. Visited Nodes

2. Parent Node

If a visited node is encountered again and it is not the parent,
a cycle exists.

import java.util.*;

public class CycleDetection {

```text
public static void main(String[] args) {

    Map<Integer, List<Integer>> graph =
        new HashMap<>();

    graph.put(1, Arrays.asList(2, 3));
    graph.put(2, Arrays.asList(1, 4));
    graph.put(3, Arrays.asList(1, 4));
    graph.put(4, Arrays.asList(2, 3));

    Set<Integer> visited =
        new HashSet<>();

    boolean cycle =
        dfs(graph, 1, -1, visited);

    System.out.println(
        "Cycle Found: " + cycle
    );

}

public static boolean dfs(

    Map<Integer, List<Integer>> graph,

    int node,

    int parent,

    Set<Integer> visited

) {

    visited.add(node);

    for(int neighbor : graph.get(node)) {

        if(!visited.contains(neighbor)) {

            if(dfs(
                graph,
                neighbor,
                node,
                visited
            )) {

                return true;

            }

        }

        else if(neighbor != parent) {

            return true;

        }

    }

    return false;

}
```

}
