TASK 2: WHAT IS DATA BINDING?
HOW MANY TYPES OF DATA BINDING ARE THERE?
======================================================================

Definition:
-----------

Data Binding is the mechanism that synchronizes data between the
component (TypeScript code) and the view (HTML template).

It helps in transferring data between UI and application logic.

======================================================================
TYPES OF DATA BINDING IN ANGULAR
======================================================================

There are 4 Types of Data Binding:

1. Interpolation
2. Property Binding
3. Event Binding
4. Two-Way Binding

======================================================================
1. INTERPOLATION
======================================================================

Used to display data from component to HTML.

Syntax:

{{ variableName }}

Example:

Component:

name = "John";

HTML:

<h1>{{name}}</h1>

Output:

John

Flow:

Component --> UI

ASCII:

Component
    |
    v
{{ name }}
    |
    v
 Display Data

======================================================================
2. PROPERTY BINDING
======================================================================

Used to bind component data to HTML element properties.

Syntax:

[property]="value"

Example:

<img [src]="imageUrl">

Flow:

Component --> HTML Attribute

ASCII:

Component Value
        |
        v
[src]="imageUrl"
        |
        v
HTML Element

======================================================================
3. EVENT BINDING
======================================================================

Used to capture user actions and send them to component.

Syntax:

(event)="method()"

Example:

<button (click)="saveData()">

Flow:

UI --> Component

ASCII:

Button Click
      |
      v
saveData()
      |
      v
Component

======================================================================
4. TWO-WAY DATA BINDING
======================================================================

Used for communication in both directions.

Syntax:

[(ngModel)]="value"

Example:

<input [(ngModel)]="username">

Flow:

Component <--> UI

ASCII:

          User Input
                ^
                |
                |
Component <----> UI

======================================================================
SUMMARY OF DATA BINDINGS
======================================================================

            Data Binding
                  |
    +-------------+-------------+
    |             |             |
    v             v             v

Interpolation  Property      Event
                                |
                                v

                         Two-Way Binding

======================================================================
SHORT ANSWER
======================================================================

Data Binding is the process of synchronizing data between the component
and the view. Angular provides four types of data binding:

1. Interpolation
2. Property Binding
3. Event Binding
4. Two-Way Binding

-----------

REST API stands for:

Representational State Transfer Application Programming Interface

It is a set of rules that allows communication between a client

----

-----

PUT
----

DELETE
------

======================================================================

----------

understand how a class should behave and be processed.

TASK 12: CAN YOU CREATE A TYPESCRIPT CLASS WITH A CONSTRUCTOR AND A FUNCTION?
======================================================================



class Employee {

    id: number;
    name: string;

    // Constructor

    constructor(id: number, name: string) {

        this.id = id;
        this.name = name;

    }

    // Function

    displayEmployee(): void {

        console.log(
            "Employee ID: " + this.id
        );

        console.log(
            "Employee Name: " + this.name
        );

    }

}

let emp = new Employee(101, "John");

emp.displayEmployee();

Employee Name: John

======================================================================

Constructor:
------------
Used for initializing object values when an object is created.

---------

      |                         |

TASK 14: WHAT IS AN OBSERVABLE RESPONSE?
======================================================================

EXPLANATION:
------------

An Observable is an RxJS feature used for handling asynchronous data
such as API calls, user events, timers, and real-time updates.

Angular's HttpClient returns Observables. To receive the data, we use
subscribe().

CODE:
------

import { HttpClient } from '@angular/common/http';

export class EmployeeComponent {

   constructor(private http: HttpClient) { }

   getEmployees() {

      this.http.get('http://localhost:8080/employees')
         .subscribe(response => {

            console.log(response);

         });

   }

}

TASK 15: WHAT IS THE FLOW OF YOUR ANGULAR PROJECT?

------------

A typical Angular application follows a layered architecture.

The flow generally starts from the User Interface (UI), moves through
the Component and Service layers, communicates with the Backend through
a REST API, retrieves data from the Database, and then sends the
response back to the UI.

------

  v

  |
  v

  |
  v

  |
  v

Response

  |
  v

  |
  v

  |
  v

HTML View

======================================================================
EXAMPLE: DISPLAY EMPLOYEE DATA
======================================================================

employee.component.ts

import { Component, OnInit } from '@angular/core';
import { EmployeeService } from './employee.service';

export class EmployeeComponent implements OnInit {

   employees: any[] = [];

   constructor(
      private employeeService: EmployeeService
   ) { }

   ngOnInit() {

      this.employeeService
          .getEmployees()
          .subscribe(data => {

              this.employees = data;

          });

   }

}

---------------------------------------------------------------------

employee.service.ts

import { HttpClient } from '@angular/common/http';

export class EmployeeService {

   constructor(
      private http: HttpClient
   ) { }

   getEmployees() {

      return this.http.get(
         'http://localhost:8080/employees'
      );

   }

}

---------------------------------------------------------------------

employee.component.html

<ul>

   <li *ngFor="let emp of employees">

      {{ emp.name }}

   </li>

</ul>

======================================================================
STEP BY STEP EXECUTION
======================================================================

1. User opens Employee Page.

2. EmployeeComponent is loaded.

3. ngOnInit() gets executed.

4. EmployeeComponent calls EmployeeService.

5. EmployeeService sends HTTP request using HttpClient.

6. REST API receives the request.

7. Backend accesses the database.

8. Database returns employee records.

9. REST API sends JSON response.

10. Service receives the response.

11. Component gets the data through subscribe().

12. HTML page displays the employee list.
